# 🚀 Exclusive - Static Frontend Project

A clean, responsive static frontend project showcasing modern UI layouts. No complex build tools, package managers, or backend configurations required!

---

## ✨ Features

- 🔹 Pure HTML/CSS/JavaScript – zero dependencies
- 🔹 Fully responsive design
- 🔹 Multi-page layout (Home, About, Contact, Cart, etc.)
- 🔹 Easy to customize and extend
- 🔹 Ideal for learning, prototyping, or portfolio showcase

---

## 🛠️ Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari, etc.)
- A code editor (e.g., [VS Code](https://code.visualstudio.com/)) – *optional but recommended*

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Benjaminofili/exclusive.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd exclusive
   ```

3. **Run the project:**
   
   **Option A – Direct Open:**  
   Simply open any HTML file (e.g., `index.html`, `about.html`, `contact.html`, `cart.html`) directly in your preferred web browser.

   **Option B – Live Server (Recommended for Development):**  
   - Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code  
   - Right-click any HTML file → *"Open with Live Server"*  
   - Enjoy hot-reloading as you code! 🎯

## 🎨 Customization Tips

- Edit `css/styles.css` to modify colors, fonts, and layout
- Update content directly in the HTML files
- Add new pages by duplicating an existing template and updating links
- Extend functionality with vanilla JavaScript in `js/script.js`
